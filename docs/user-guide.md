# Omni Download 使用手册

Omni Download 是一个下载管理器：多连接下载 HTTP、HTTPS 和 FTP 链接，下载磁力链接和种子，并且能接管浏览器里的下载。本手册按“想做什么”来组织；遇到问题先看 [常见问题](faq.md)。

## 安装

到 [Releases](https://github.com/VoidDel/OmniDownloadeManager/releases/latest) 下载对应系统的安装包。

| 系统 | 安装包 | 说明 |
|---|---|---|
| Windows 10 / 11 | `Omni.Download_<版本>_x64-setup.exe` | 只装到当前用户，不需要管理员权限 |
| macOS 12 及以上（Apple Silicon） | `Omni.Download_<版本>_aarch64.dmg` | 不提供 Intel 版 |
| Linux | `.deb`、`.rpm` 或 `.AppImage` | deb / rpm 体积小，依赖系统的 WebKitGTK；AppImage 自带依赖 |

安装包目前没有代码签名，所以第一次运行时系统会拦一下：

- **Windows**：SmartScreen 提示“已保护你的电脑”时，点“更多信息”再点“仍要运行”。
- **macOS**：提示“已损坏，无法打开”时，在终端执行 `xattr -cr "/Applications/Omni Download.app"`，或到“系统设置 › 隐私与安全性”里点“仍要打开”。

卸载用系统自带的方式即可。Windows 的卸载程序会同时删除浏览器通信配置和开机启动项。

## 第一次打开

第一次启动会出现三步向导，跳过也可以，里面的内容都能在设置里再改：

1. **语言和下载文件夹**：默认是系统的“下载”文件夹。
2. **浏览器**：列出本机找到的浏览器，点“获取扩展”安装浏览器扩展。
3. **后台运行**：是否随系统启动，关闭窗口时是否留在托盘。

## 添加下载

有这些方式：

- **粘贴链接**：复制链接后，在任务列表上按 `Ctrl+V`，会打开“新建下载”并填好链接。
- **悬浮球**：在“设置 › 常规”里打开“显示悬浮球”后，屏幕上会有一个始终在最前面的小圆球，显示总下载进度和速度。把网页上的链接拖到球上即可下载（一个链接弹出确认小窗，多个链接打开“新建下载”），也可以拖入 `.torrent` 文件。按住拖动可以移动它，双击打开主窗口，右键有“全部开始 / 全部暂停 / 隐藏悬浮球”等菜单。
- **监视剪贴板**：在“设置 › 常规”里打开后，复制视频、压缩包、安装包、镜像、文档等文件的下载链接或磁力链接时，会弹出确认小窗。普通网页链接、图片链接、已在列表里的链接不会弹出；按 `Esc` 忽略。
- **新建下载**：点“新建下载”或按 `Ctrl+N`。每行一个链接，可以混着写 HTTP、FTP、磁力链接和种子文件的路径。
- **批量下载**：一组编号连续的文件，在链接里用方括号写出范围，例如 `https://example.com/img[1-50].jpg`、`part[01-12].rar`（以 0 开头时保持位数）、`[a-z]`、`[0-100:5]`（步长 5）。一个链接里可以有多个范围。“新建下载”会显示展开成了多少个任务，一次最多 1000 个。
- **种子文件**：把 `.torrent` 文件拖进窗口，或在“新建下载”里点“打开种子文件”。安装版还可以直接双击种子文件、点击网页上的磁力链接。
- **从浏览器**：装好扩展后，在浏览器里点下载就会交给 Omni Download，见 [接管浏览器的下载](#接管浏览器的下载)。

“新建下载”会先向服务器询问文件信息，然后显示文件名、大小、是否支持断点续传。问不到也可以添加，开始下载时会再试。每个任务可以单独设置：

| 选项 | 作用 |
|---|---|
| 文件名 | 留空用服务器给的名字 |
| 保存到 | 这个任务的保存位置 |
| 连接数 | 同时打开几个连接下载这个文件；留空按设置（默认自动调节）。服务器不支持分段时只用一个 |
| 限速 | 只限这个任务，例如 `500K`、`2M`；留空不限 |
| 高级 | Referer、Cookie、User-Agent、镜像地址、校验值、代理 |
| 添加后立即开始 | 取消勾选则只添加，之后手动开始 |

**连接数**：默认“自动调节”——下载时按实际速度增减连接（最多到“设置 › 下载 › 连接数上限”，默认 16），服务器拒绝更多连接时自动降低；某个连接明显变慢时（例如服务器对单个连接限速），会换一个新连接接着下它那一段。下载过程中也可以在详情面板的“连接”里改成固定的数或改回“自动”，立即生效。

**镜像地址**：同一个文件在多个服务器上都有时（例如开源软件的镜像站），可以在“高级”里填上其他地址，每行一个（只用于单个 HTTP 链接）。下载时各个连接会分摊到原链接和这些镜像上；文件大小对不上、不支持分段下载或下载中出错的镜像会自动停用，不影响任务本身。

同名文件已存在时默认自动改名（`文件 (1).zip`），可以在“设置 › 下载”里改成覆盖，或改成询问：任务会停下来，显示“文件已存在”，由你选择重命名还是覆盖（暂时不选也可以，之后双击任务再选）。

**需要账号的下载**：服务器要求登录时（网页常见的是弹出用户名和密码框的那种，HTTP 的 Basic 和 Digest 认证），任务会停下来显示“需要登录”，并弹出对话框让你填用户名和密码；填好后继续下载。账号也可以直接写在链接里（`https://用户:密码@主机/路径`）。密码加密保存，只发给这个链接所在的服务器，列表和“复制链接”里不显示。用网页表单登录的网站不是这种情况，请从浏览器里发起下载，见 [接管浏览器的下载](#接管浏览器的下载)。

## 管理任务

左侧按状态（全部任务、进行中、已完成、种子、失败、回收站）和文件类型（视频、音乐、文档、压缩包、程序、镜像、其他）筛选；类型按扩展名自动归类。

选中任务后用工具栏、右键菜单或键盘操作：

| 操作 | 说明 |
|---|---|
| 开始 / 暂停 | 支持断点续传的任务暂停后从原处继续；不支持的只能重新下载 |
| 打开 / 打开文件夹 | 双击已完成的任务即可打开文件 |
| 复制链接 | 复制原始下载链接（不含账号密码） |
| 删除 | 移到回收站，文件不动；在回收站里可以还原 |
| 彻底删除 | 删除任务记录和未完成的临时文件；可勾选同时删除已下载完成的文件 |
| 重新下载 | 从头再下一次。服务器上的文件变了、已完成的文件被删掉，或校验不符时会出现 |

同时下载的任务数有上限（默认 3 个，“设置 › 下载”可改），其余任务显示“等待中”，前面的完成后自动开始。

**调整顺序**：列表按“列表顺序”排列时（工具栏右侧的排序菜单；新任务排在最后），把鼠标移到一行上，左端会出现拖动手柄，按住它把任务拖到别的位置，选中多个时一起移动，按 `Esc` 取消。也可以用 `Alt+↑` / `Alt+↓`，或右键菜单里的“移到最前”“移到最后”。等待中的任务按这个顺序开始。点表头按某一列排序时不能拖动；同一列点第三次回到列表顺序。

**详情面板**：点工具栏右侧的面板按钮，或右键选“详情”。里面有速度曲线、平均速度和最大速度、分片进度；种子任务还有文件列表、节点和 Tracker。点面板上的固定按钮后，选中任务时会自动显示详情。

**任务失败时**，详情面板会写明原因和建议的处理办法，点“重试”即可再试。网络错误会先自动重试几次（“设置 › 网络”可改次数），都失败了才标为失败。

**已完成的文件被删除或移走**后，任务会标为“文件已删除”，可以重新下载。

未完成的文件以 `.odm` 结尾，下载完成后才改成正式的名字。

## 计划任务

在“设置 › 下载”最下面：

- **定时开始**：到点后开始所有已暂停的任务，适合晚上空闲时下载。
- **定时停止**：到点后暂停所有正在下载和等待中的任务。
- **重复**：选择上面两项在每周哪几天生效。
- **全部下载完成后**：退出 Omni Download、睡眠或关机。睡眠和关机前会弹出 60 秒倒计时，可以取消或立即执行；关机前会先保存下载进度。

## 文件校验

很多下载页面会给出文件的 MD5、SHA-1 或 SHA-256 值，用来确认文件完整、没有被篡改。

- **下载前填写**：在“新建下载 › 高级”的“校验值”里粘贴网站给出的值（只用于单个 HTTP / FTP 链接）。可以直接粘贴十六进制值，也可以带上算法名，例如 `sha256:…`，或者 `.sha256` 文件里的一整行。下载完成后自动核对；对不上时任务标为“校验不符”，文件保留，会弹出通知，可以选“重新下载”。
- **下载后核对**：在已完成任务的详情面板里，“文件校验”一栏可以粘贴校验值来核对，或点“计算 MD5 / SHA-1 / SHA-256”算出文件的值，和网站上的对比。

种子任务下载时会逐块核对数据，不需要另外校验。

## 限速

- **全局限速**：点窗口右下角的“不限速”，选一个预设值或自定义。托盘图标的菜单里也能改。
- **单个任务**：在“新建下载”或浏览器下载的确认窗口里填。
- **BT 上传限速**：在“设置 › BT”。

速度的写法：`500`（KB/s）、`500K`、`2M`、`1.5MB/s`；留空表示不限。

## 接管浏览器的下载

支持 Chrome、Edge、Brave、Chromium 和 Firefox。

1. 在浏览器里安装 Omni Download 扩展。扩展尚未上架商店时，按 [README 的“浏览器扩展”一节](../README.md#浏览器扩展) 手动加载。
2. 运行一次 Omni Download，它会为本机的浏览器写好通信配置。“设置 › 浏览器”里可以看到每个浏览器的状态。

之后在浏览器里点下载：

- 默认会弹出一个小窗口，确认文件名和保存位置后点“开始下载”。也可以选“稍后下载”（只添加不开始）或“改用浏览器下载”。
- 勾选“这个网站的下载以后不再询问”，该网站的下载以后直接开始。这些网站列在“设置 › 浏览器 › 不再询问的网站”，可以随时移除。
- 网站的登录信息（Cookie）和来源页（Referer）会一起带过来，所以需要登录才能下载的文件也能下。
- Omni Download 没在运行时会被自动启动。

不想让某次下载被接管：**按住 Alt 再点链接**。

其他入口：

- 右键链接 ›“用 Omni Download 下载链接”；右键图片、视频或音频 ›“用 Omni Download 下载”。
- 右键页面 ›“用 Omni Download 下载本页的文件链接…”。
- 按 `Alt+Shift+D`：下载当前页面本身，例如在浏览器里打开的 PDF 或视频。
- 点扩展图标可以看到连接状态和最近的下载，并能临时关掉接管。

在扩展的“选项”里可以设置接管规则：

| 规则 | 默认 | 说明 |
|---|---|---|
| 接管浏览器下载 | 开 | 总开关 |
| 最小文件大小 | 1 MB | 更小的文件留在浏览器；大小未知的会接管 |
| 只接管这些扩展名 | 空 | 留空表示所有文件 |
| 不接管这些扩展名 | 空 | 例如 `pdf jpg` |
| 不接管的网站 | 空 | 每行一个，包括子域名 |
| 直接开始 | 关 | 不弹确认窗口 |

**Snap、Flatpak 版浏览器**用不了默认的通信方式：在“设置 › 浏览器”打开“备用通道”，把配对码填到扩展选项里。

**媒体嗅探**：页面播放视频或音频时，扩展会把找到的媒体列在工具栏弹出面板的“此页的媒体”里，图标上显示找到的数量。点右边的下载按钮即交给 Omni Download。

- 画面和声音分开的视频（B 站等网站的 DASH 播放方式）列为一项“视频（自动合并声音）”：Omni Download 分别下载后合并成一个 MP4。HLS 视频流的声音是单独的播放列表时（fMP4 格式）也会一起下载并合并。
- 文件名：地址里的名字有意义就用它；是 `videoplayback`、`index`、一串哈希或数字这类时，改用页面标题（去掉“_哔哩哔哩_bilibili”“ - YouTube”等网站名），并补上正确的扩展名。
- 不会列出：视频分段、很小的声音文件、DASH 清单，以及 YouTube 播放器的视频流（地址会过期，网页版也改用了专有协议，无法直接下载）。
- 换到别的页面后列表清空。

## HLS 视频流（m3u8）

很多网站的视频是切成小段、由 `.m3u8` 播放列表串起来的（HLS）。把 `.m3u8` 链接加到“新建下载”里，Omni Download 会下载所有分段并按顺序合并成一个视频文件：

- 有多种清晰度时自动选最高的一档。
- 用 AES-128 加密的分段会自动解密；其他加密方式（如 SAMPLE-AES、DRM）不支持。
- 合并结果是 `.ts` 文件（分段是 fMP4 时为 `.mp4`），常见播放器都能直接播放。需要 MP4 的话可以用 FFmpeg 等工具转换封装。
- 支持暂停和继续，已下载的分段不会重下。
- 直播流（播放列表没有结束标记）暂不支持录制。
- 下载前不知道总大小，进度中的大小是根据已下载部分估算的。

## BT 与磁力链接

- 添加磁力链接或种子后，先“获取种子信息”，然后可以在文件列表里勾选要下载的文件；下载过程中也能在详情面板的“文件”里改。
- 下载完成后默认继续做种（把文件上传给其他人）。暂停“做种中”的任务即停止；也可以在“设置 › BT”里设置分享率或做种时长，到了自动停。
- 网页上的种子文件（`.torrent`）会先作为普通文件下载下来，下载完成后自动打开“新建下载”，在里面选择要下载的内容。不需要的话，可以在“设置 › BT”里关掉“下载完成的种子文件自动打开”。
- “种子”筛选里列出所有种子任务。

“设置 › BT”里的监听端口、DHT、UPnP 改动后要重启应用才生效。磁力链接一直找不到节点时，先确认 DHT 是开着的。

**附加 Tracker**：在“设置 › BT”里打开“附加 Tracker”后，公开的种子和磁力链接会额外使用你填的 Tracker，帮助找到更多节点。可以在“Tracker 列表”里逐行填写（支持 `http`、`https`、`udp`），也可以在“订阅列表”里逐行填写多个网址或本地文件（例如网上维护的公共 Tracker 列表），应用每天自动更新一次，也可以点“更新”立即获取；某个订阅暂时获取不到时，沿用它上次的结果。私有种子（PT 站的种子）不会附加。改动对之后开始的任务生效，正在下载的任务暂停再继续即可。

**IP 过滤**：在“设置 › BT”里打开“IP 过滤”后，不会与列表中的 IP 连接，也拒绝它们连入。过滤列表可以逐行填写多个网址或本地文件（任何一个获取失败时不会更新，继续使用原来的规则），支持 P2P、eMule `ipfilter.dat`、CIDR 格式，gzip 压缩的也可以；还可以在“手动屏蔽的 IP”里逐行填写单个 IP、CIDR 或范围。改好后点“更新”，下次启动应用时生效。

## FTP

- 支持 `ftp://` 和 `ftps://`，匿名或带账号。账号可以写在链接里（`ftp://用户:密码@主机/路径`），也可以在“新建下载”里填。密码加密保存，列表和“复制链接”里不显示。
- 服务器支持续传时，会用多个会话同时下载一个文件（“设置 › 网络 › FTP 会话数”）。服务器限制同一账号的连接数时把它调小。
- 默认用被动模式；只有服务器要求时才改成主动模式。
- 代理设置只对 HTTP 下载有效，FTP 始终直连。
- **下载整个文件夹**：链接以 `/` 结尾时（例如 `ftp://example.com/pub/release/`）当作文件夹，“新建下载”会列出其中所有文件（包括子文件夹），可以取消勾选不要的。每个文件各建一个任务，保存到“下载文件夹/文件夹名/子文件夹”下，保持原来的目录结构。一次最多列出 5000 个文件。

## 在后台运行

- **关闭窗口**默认只是收到托盘，下载继续。要真正退出，在托盘图标的菜单里点“退出”；退出时会保存每个任务的进度，下次启动自动继续。
- **托盘图标**：单击显示窗口。菜单里有新建下载、全部开始、全部暂停、限速和退出。有任务在下载时图标上有一个绿点，鼠标停在上面显示当前速度。
- **随系统启动**：开机后只出现在托盘，不弹窗口。
- **通知**：下载完成或失败时通知，窗口在前台时不打扰。Windows 上点通知会打开文件所在的文件夹。
- **全局快捷键**：可以给“显示或隐藏主窗口”和“新建下载”各设一个，在其他应用里也有效。默认不设。

这些都在“设置 › 常规”里。

## 更新

启动后会自动检查一次新版本（可在“设置 › 常规”关掉），也可以点“检查更新”手动查。有新版本时先显示更新说明，由你决定何时安装；安装时正在进行的下载会暂停，重启后自动继续。

## 设置一览

| 页 | 内容 |
|---|---|
| 常规 | 随系统启动、关闭到托盘、通知、悬浮球、监视剪贴板、完成提示音、全局快捷键、版本与更新、日志、导出与导入任务列表、帮助与反馈 |
| 外观 | 界面语言、浅色 / 深色 / 跟随系统、主题、强调色、窗口材质、列表密度 |
| 下载 | 默认下载文件夹、同时下载的任务数、自动调节连接数与连接数上限（关闭时为每个任务的连接数）、文件已存在时的处理（自动重命名、覆盖或询问）、启动时继续未完成的下载、标记文件来自互联网（Windows、macOS） |
| 网络 | 代理、User-Agent（默认“自动”：先用浏览器的标识，服务器拒绝时自动换用其他常见标识；也可以选定一个或自定义）、连接超时、无响应超时、失败重试次数、是否允许从 HTTPS 跳转到 HTTP、FTP 会话数与传输模式 |
| BT | 做种、分享率与做种时长、上传限速、监听端口、DHT、UPnP、磁力链接关联 |
| 浏览器 | 各浏览器的连接状态、接管前是否询问、不再询问的网站、备用通道 |

设置改动即时保存。超时这类设置对之后开始的下载生效；连接数相关的设置对正在下载、没有单独设置连接数的任务也立即生效。

**标记文件来自互联网**（默认打开）：下载完成的文件会带上和浏览器下载的文件一样的来源标记。Windows 上运行这样的程序前系统会先确认，Office 用受保护的视图打开文档；macOS 上第一次打开时系统会检查并确认。来自本机和局域网的文件不标记，种子任务的文件也不标记。

**从 HTTPS 跳转到 HTTP**（默认不允许）：加密的链接被服务器转到不加密的地址时，下载会停止并说明原因，以免文件和 Cookie 在网络上暴露。确实需要时可以在“设置 › 网络”里允许。

**导出与导入任务列表**：“设置 › 常规 › 任务列表”。导出把回收站以外的所有任务写进一个 JSON 文件；默认不含 Cookie、自定义请求头和密码，勾选后才包含（文件里是明文）。导入时，未完成的任务以“已暂停”加入、从头下载，已完成的仍是已完成；列表里已有的任务（链接、保存位置和文件名都相同）会跳过。从种子文件添加的任务导出为磁力链接。下载进度不随文件导出。

## 键盘操作

macOS 上把 `Ctrl` 换成 `⌘`。

| 按键 | 作用 |
|---|---|
| `Ctrl+N` | 新建下载 |
| `Ctrl+F` | 搜索任务（名称、链接或保存位置，`Esc` 清空） |
| `Ctrl+V` | 在任务列表上粘贴链接，新建下载 |
| `Ctrl+,` | 打开或关闭设置 |
| `↑` `↓` `Home` `End` | 在任务列表里移动 |
| `Shift+↑` / `Shift+↓` | 连续多选 |
| `Ctrl+A` | 全选 |
| `Alt+↑` / `Alt+↓` | 把选中的任务上移或下移一位（按列表顺序排列时） |
| `空格` | 开始或暂停选中的任务 |
| `Enter` | 打开已完成的文件 |
| `Delete` | 删除（移到回收站）；`Shift+Delete` 彻底删除 |
| `菜单键` 或 `Shift+F10` | 打开选中任务的菜单 |
| `Esc` | 取消选择，或关闭对话框和菜单 |

## 数据存放在哪里

| | Windows | macOS | Linux |
|---|---|---|---|
| 设置（`settings.toml`） | `%APPDATA%\app.omnidownload.desktop` | `~/Library/Application Support/app.omnidownload.desktop` | `~/.config/app.omnidownload.desktop` |
| 任务记录（`omni.db`） | 同上 | 同上 | `~/.local/share/app.omnidownload.desktop` |
| 日志 | `%LOCALAPPDATA%\app.omnidownload.desktop\logs` | `~/Library/Logs/app.omnidownload.desktop` | `~/.local/share/app.omnidownload.desktop/logs` |

日志文件夹可以从“设置 › 常规 › 日志”直接打开。浏览器带过来的 Cookie 和账号密码（FTP 的，以及服务器要求登录时填的）在任务记录里是加密保存的。Windows 的卸载程序可以勾选同时删除应用数据；其他系统卸载后这些文件还在，想彻底清理就手动删除上面的文件夹。
