# 常见问题

用法见 [使用手册](user-guide.md)。这里没有答案的问题，请 [提交反馈](https://github.com/VoidDel/OmniDownloadeManager/issues/new/choose)，并附上日志（“设置 › 常规 › 日志”）。

## 安装与启动

### Windows 提示“已保护你的电脑”

安装包还没有代码签名。点“更多信息”，再点“仍要运行”。

### macOS 提示“已损坏，无法打开”

同样是因为没有签名和公证。在终端执行：

```bash
xattr -cr "/Applications/Omni Download.app"
```

或者到“系统设置 › 隐私与安全性”里点“仍要打开”。

### 有 Intel Mac 的版本吗

没有，macOS 只提供 Apple Silicon 版。

### 关掉窗口后它还在运行

默认关闭窗口只是收到托盘，这样下载不会中断，浏览器也能随时把下载交过来。要退出，在托盘图标的菜单里点“退出”。不想要这个行为，关掉“设置 › 常规 › 关闭窗口时最小化到托盘”。

### 它占多少内存

应用本身大约 10–25 MB。界面由系统的 WebView 绘制（Windows 上是 WebView2），窗口打开时这部分另外占 120–150 MB。窗口收到托盘后界面会被完全关闭，只留下应用本身；再次打开时重新加载，大约要半秒到一秒。

## 下载

### 速度没有预期的快

- 看详情面板里的连接数。服务器不支持分段下载时只能用一个连接，这时速度取决于服务器。
- 确认没有开限速：窗口右下角应显示“不限速”，任务自身的限速也留空。
- 有的服务器限制单个 IP 的连接数或速度，连接开得越多反而越慢。在“新建下载”里把连接数调小试试。
- 走代理时，速度受代理限制。

### 任务显示“不支持断点续传”

服务器不允许从中间开始下载。这种任务可以下，但暂停或断线后只能从头再来。

### 暂停后继续，进度从头开始了

两种情况：服务器不支持断点续传；或者服务器上的文件在这期间变了（任务会提示“服务器上的文件已变更”），已下载的部分对不上新文件，只能重新下载。

### 任务失败了

打开任务的详情面板，里面写着原因和建议的处理办法。最常见的几种：

| 提示 | 通常的原因 | 处理 |
|---|---|---|
| 服务器拒绝访问 | 链接过期，或只允许从原网页下载 | 回到浏览器重新点下载，让扩展带上登录信息 |
| 服务器上没有这个文件 | 链接失效 | 到原网页重新获取链接 |
| 网络连接失败 / 连接超时 | 网络或代理有问题 | 检查网络和“设置 › 网络”里的代理，然后重试 |
| 安全连接失败，证书无效 | 系统时间不对，或代理、安全软件替换了证书 | 校正系统时间；确认代理可信 |
| 磁盘空间不足 | — | 清理出空间后点“重试”，已下载的部分会保留 |

### 需要登录的文件下不了

从浏览器里发起下载，不要复制链接。扩展会把网站的 Cookie 和来源页一起交给 Omni Download。手动添加时，可以在“新建下载 › 高级”里填 Cookie 和 Referer。

### `.odm` 文件是什么

还没下完的文件。下载完成后会自动改成正式的文件名。不要手动改名或删除它，否则任务无法续传。

### 已完成的任务显示“文件已删除”

文件被删掉或移出了保存位置。任务记录还在，可以点“重新下载”。

### 删除任务会删掉文件吗

不会。“删除”只是把任务移到回收站，文件原样保留。在回收站里“彻底删除”时，可以勾选是否同时删除已下载完成的文件。

### 断电或死机后进度还在吗

在。进度每秒写入磁盘一次，重新启动后从记录的位置继续。可以在“设置 › 下载”里关掉“每秒把进度写入磁盘”来减少磁盘写入，代价是意外断电后可能要多重下一小段。

## 浏览器

### 浏览器里点下载，没有交给 Omni Download

依次检查：

1. 扩展图标的弹窗里显示“已连接”吗？没有的话按弹窗里的提示处理。
2. 扩展弹窗里的“接管浏览器下载”是打开的吗？
3. 文件是否小于 1 MB？默认小文件留在浏览器，可以在扩展选项里改“最小文件大小”。
4. 该网站或扩展名是否在扩展选项的“不接管”列表里？
5. Omni Download 的“设置 › 浏览器”里，这个浏览器的状态是“已就绪”或“已连接”吗？不是的话点“重新写入通信配置”，然后重启浏览器。

### “设置 › 浏览器”里显示“指向另一个安装”

浏览器的通信配置指向了另一份 Omni Download（比如旧的安装位置或开发版）。点“重新写入通信配置”让它指向当前这一份。

### Snap / Flatpak 版的 Firefox 或 Chromium 连不上

沙盒里的浏览器不能启动本机程序。在“设置 › 浏览器”里打开“备用通道”，把配对码填到扩展选项里，并把连接方式选成“备用通道”或“自动”。

### 某一次下载想让浏览器自己下

按住 Alt 再点链接；或者在确认窗口里点“改用浏览器下载”。

### 每次都弹确认窗口，太烦

在确认窗口里勾选“这个网站的下载以后不再询问”；或者在“设置 › 浏览器”关掉“接管前询问”，所有下载都直接开始。

## BT

### 磁力链接一直停在“获取种子信息”

磁力链接本身不含文件信息，要先从其他节点取到。检查：

- “设置 › BT”里的 DHT 是否打开（改动后要重启应用）。
- 这个种子是否还有人在做种。冷门或很老的种子可能一个节点都找不到。
- 网络是否屏蔽了 BT 流量（公司、学校的网络常见）。

### 下载完成后还在上传

这是做种，BT 下载靠大家互相上传。不想做种：暂停这个任务；或在“设置 › BT”关掉“下载完成后做种”，或设置分享率、做种时长，到了自动停。上传占带宽时可以设“上传限速”。

### 只想下种子里的部分文件

添加时在文件列表里只勾选需要的；下载中也可以在详情面板的“文件”里改。

## 其他

### 全局快捷键设不上

提示被占用时，说明另一个程序已经注册了这组按键，换一组即可。两个动作不能用同一组按键。

### 检查更新提示“无法检查更新”

多半是连不上 GitHub。稍后再试，或直接到 [Releases](https://github.com/VoidDel/OmniDownloadeManager/releases/latest) 下载新版安装包覆盖安装，任务和设置都会保留。

### 怎么反馈问题

在 [Issues](https://github.com/VoidDel/OmniDownloadeManager/issues/new/choose) 里选“问题反馈”，写清楚做了什么、看到了什么，并附上当天的日志文件（“设置 › 常规 › 日志 › 打开文件夹”）。日志里可能有下载链接和文件路径；介意的话先把它们抹掉。
